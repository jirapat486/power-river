# ถุงปริศนาวิศวกรน้อย

เกมทดลองวัตถุนำไฟฟ้าสำหรับนักเรียนประถม ลากวัตถุ 20 ชิ้นไปต่อสายไฟที่ขาดกลางแม่น้ำ แล้วดูว่าไฟถึงเมืองจิ๋วไหม

เล่นได้ที่: https://jirapat486.github.io/power-river/

## ติดตั้งบน iPad
1. เปิดลิงก์ด้านบนใน **Safari** (ต่ออินเทอร์เน็ต)
2. กดปุ่มแชร์ ⬆️ → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดจากไอคอนบนหน้าจอโฮม เล่นแบบเต็มจอ และเล่นออฟไลน์ได้หลังเปิดครั้งแรก

เมื่ออัปเดตเกม เวอร์ชันใหม่จะเริ่มใช้ในการเปิดแอปครั้งถัดไป (ขณะต่ออินเทอร์เน็ต)
